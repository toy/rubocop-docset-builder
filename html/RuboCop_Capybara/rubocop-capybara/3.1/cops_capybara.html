Capybara/AbsoluteXPathInElementScope

Enabled by default Safe Supports autocorrection Version Added Version Changed

Pending

Yes

No

3.1

-

Checks for absolute XPath searches on Capybara elements.

An XPath starting with // searches from the document root, even when the query is called on an element. Use .// to stay within it. Direct RSpec let and named subject element definitions are recognized.

Examples

# bad
page.find('.dialog').find(:xpath, '//button')
dialog = page.find('.dialog')
dialog.find(:xpath, '//button')
RSpec.describe 'dialog' do
  let(:dialog) { find('.dialog') }
  it { dialog.find(:xpath, '//button') }
end

# good
page.find('.dialog').find(:xpath, './/button')
page.find(:xpath, '//button')

Capybara/ChainedFind

Enabled by default Safe Supports autocorrection Version Added Version Changed

Pending

Yes

Always

3.1

-

Avoid chaining find methods and combine selectors.

Combining selectors into a single find call is more efficient than chaining multiple find calls, as it reduces the number of DOM queries. Only recognizable Capybara finder chains with string locators are checked. Set DefaultSelector to match Capybara.default_selector, or to null if it varies at runtime. Autocorrection requires css and literal strings.

Examples

# bad
page.find('#foo').find('.bar')
page.find('#foo').find('.bar').find('.baz')

# good
page.find('#foo .bar')
page.find('#foo .bar .baz')
find('#form').find(:button, 'Save')

Configurable attributes

DefaultSelector

css

String

Capybara/FindAllFirst

Enabled by default Safe Supports autocorrection Version Added Version Changed

Enabled

Yes

Always (Unsafe)

2.22

3.0

Enforces use of first instead of all with first or [0].

Safety

With default options, all(…​).first and all(…​)[0] return nil when no element matches, while first(…​) raises an exception. Autocorrection can break code that depends on nil.

Examples

# bad
all('a').first
all('a')[0]

# good
first('a')

Capybara/IgnoredQueryOption

Enabled by default Safe Supports autocorrection Version Added Version Changed

Pending

Yes

Always

3.1

-

Checks for query options that have no effect in Capybara.

Count options passed to singular finders are not autocorrected because removing them may conceal the author’s intent.

This cop targets Capybara’s built-in selectors. Set DefaultSelector to match Capybara.default_selector, or to null if it varies at runtime. Queries using custom or unknown selectors are skipped.

Examples

# bad
find('.row', count: 3)
find(:css, '.item', exact: true)
find('.item', text: /foo/, exact_text: true)
all(:css, '.item', match: :first)
expect(page).to have_css('.item', count: 3, minimum: 1)

# good
all('.row', count: 3)
find(:css, '.item')
find('.item', text: /foo/)
all(:css, '.item')
expect(page).to have_css('.item', count: 3)

DefaultSelector: custom

# bad
find(:css, '.item', text: /foo/, exact_text: true)

# good
find('.item', text: /foo/, exact_text: true)

Configurable attributes

Name Default value Configurable values

DefaultSelector

css

String

-

Enforces use of Element#[] instead of native.attribute.

This cop’s autocorrection is unsafe because attribute values may differ between the driver API and Capybara’s Element#[].

Capybara/VisibilityOption

Enabled by default Safe Supports autocorrection Version Added Version Changed

Pending

Yes

Always

3.1

-

Checks for boolean values passed to Capybara’s visible option.

visible: false finds both visible and hidden elements, rather than only hidden elements. Use :all, :hidden or :visible instead. Only true is autocorrected, to :visible.

This cop targets Capybara’s built-in selectors. Set DefaultSelector to match Capybara.default_selector, or to null if it varies at runtime. Queries using custom or unknown selectors are skipped.

Examples

# bad
find('.menu', visible: true)
expect(page).to have_css('.menu', visible: false)

# good
find('.menu', visible: :visible)
find('.menu', visible: :all)
find('.menu', visible: :hidden)

DefaultSelector: custom

# bad
find(:css, '.menu', visible: true)

# good
find('.menu', visible: true)

Configurable attributes

Name Default value Configurable values

DefaultSelector

css

String
